// Metodologia de Três Fases

A ciência por trás da previsão

Não é heurística. Não é média histórica. É uma arquitetura de Inteligência Artificial projetada para a realidade operacional dos portos brasileiros — com modelos individuais para cada unidade monitorada.

01

Fase 1

Coleta e Engenharia de Dados

Web scraping automatizado dos line-ups portuários em tempo real. Integração com API OpenWeather para telemetria climática. Ingestão de dados de frota e berços. Pipeline de limpeza, normalização e feature engineering para séries temporais de múltiplas fontes.

Web Scraping OpenWeather API Line-ups em Tempo Real Pandas / Numpy Feature Engineering
→
02

Fase 2

Treinamento do Modelo LSTM

Redes Neurais Recorrentes LSTM bidirecionais implementadas em PyTorch, treinadas individualmente por porto com janelas temporais de 30 dias. O modelo captura dependências de longo prazo — sazonalidade de safra, padrões climáticos e ciclos operacionais — que modelos lineares não conseguem modelar.

PyTorch LSTM Séries Temporais MAE / RMSE Early Stopping Modelo por Porto
→
03

Fase 3

Entrega de Insights via API e Dashboard

Modelos servidos por API REST de alta performance via FastAPI. O dashboard operacional atualiza previsões a cada 60 segundos com alertas Verde / Amarelo / Vermelho para janelas de 24h, 48h e 72h — acessíveis pelo painel ou diretamente no seu TMS via endpoint JSON.

// Para CTOs e Arquitetos de Dados

Integração em dias, não em meses.

A arquitetura foi projetada para se encaixar na sua stack atual. API REST documentada (OpenAPI 3.0), containers Docker isolados e endpoints JSON com latência <100ms — sem lock-in de infraestrutura.

🐳

Deploy Containerizado via Docker

Toda a stack — modelo LSTM, FastAPI, scraper de line-ups — roda em containers Docker orquestrados por Compose. Portável, isolado e reproduzível em qualquer cloud ou on-premise sem refatoração.

⚡

API REST de Alta Performance (FastAPI)

Endpoints assíncronos com latência típica de 50–120ms. Documentação interativa automática (Swagger / ReDoc). Compatível com qualquer TMS, WMS ou sistema de gestão de frota que consuma JSON sobre HTTP.

🔄

Pipeline de Dados Autônomo

Scraping de line-ups e telemetria climática (OpenWeather) operam de forma autônoma, alimentando os modelos com dados frescos. Zero intervenção manual para manter a acurácia das previsões ao longo do tempo.
